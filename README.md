# interactive-portfolio-site

Open-source portfolio site for Georgios Lazaridis, built with Next.js, React, TypeScript, and Tailwind CSS.

## Highlights

- cinematic, interactive landing page with custom motion effects
- portfolio sections for experience, projects, skills, education, and contact
- downloadable CV served from `public/Georgios-Lazaridis-CV.pdf`
- personal schedule page with structured day planning data

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Radix UI
- Lucide icons

## Getting started

### Prerequisites

- Node.js 20+
- Yarn 1.x

### Install dependencies

```bash
yarn install
```

### Start the development server

```bash
yarn dev
```

Open `http://localhost:3000`.

## Available scripts

```bash
yarn dev
yarn build
yarn start
yarn lint
```

## Project structure

```text
app/                    Next.js app routes
components/             UI and portfolio components
hooks/                  animation and interaction hooks
lib/                    static data and utilities
public/                 downloadable assets and media
styles/                 global styles
```
